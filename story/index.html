0 records lost · Google → Microsoft 365 · EWS → Graph

Zero-loss data migrations

I've moved customer mailboxes across providers and tenants: Google Workspace to Microsoft 365, and Microsoft 365 to Microsoft 365. I led the Google Workspace → Microsoft Graph migration with zero data loss.

When Microsoft deprecated EWS, I converted our stored Exchange IDs into Microsoft Graph IDs. I also built the restoration pipeline: snapshot → SQL via kubectl → Rails rake task via Pulumi.

Jira → Claude → GitHub · scored bug triage

AI-powered triage & review

I built a Claude skill, connected to Jira through the Atlassian MCP, that triages tickets as they come in. It reads the description, scores how likely the report is to be a valid bug, and sends probes into our GitHub repo to cross-reference the code behind it, so an engineer starts with evidence instead of a blank ticket.

Our pull requests go through Claude review, and I review code alongside it. I also review PRDs and TRDs: I work deep in the product, and those docs are the instructions every feature is built from, so they have to be right before code gets written.

↓ escalations · 24h → 1–2h partner onboarding

Self-serve tooling & automation

I build AI diagnostic tools with Claude that let Support and Customer Success answer their own questions, which cuts the tickets escalated to engineering. I also use Claude agent skills to draft pull requests.

I automate the repetitive work too: my Node.js validation script cut partner onboarding from 24 hours to 1–2 hours. And I mentor support engineers.
